## 🦆 Featured Project — Manager Access Review Assistant

**Manager Access Review Assistant** is a learning and portfolio prototype for exploring IAM, security, automation and bounded AI-assisted decision support.

It uses a fictional organization, **Ankkalinna Identity Lab Oy**, where Aku Ankka, Roope Ankka and the rest of the team have accumulated realistic access-management problems. The people are fictional. The access mess is unfortunately very believable.

The project explores:

- explainable access review and identity governance thinking
- direct-manager checks across synthetic AD and Entra data
- account-expiry and lifecycle mismatch detection
- access suggestions based on documented role and location profiles
- Service Desk request drafts with a hard no-write boundary
- human-in-the-loop design and fail-closed security thinking
- optional local AI ordering of existing evidence, with deterministic fallback
- automated tests, browser QA and security documentation

It is intentionally a **design-and-testing stage learning project**, not a production IAM system. No live tenant, employee data or access changes are involved.

## 🌿 Featured Project — NordHerb

**NordHerb** is my personal plant knowledge project, built because apparently one hobby project was not enough.

It brings together nature, application development and practical API integration:

- a shared collection of **140 plant entries in Finnish and English**
- search, plant detail pages and clear safety labels
- a mobile photo-based plant suggestion feature using **Pl@ntNet**
- a **React Native / Expo / TypeScript** mobile app
- a **Java / Spring Boot** API connecting the app to the plant identification service

I use AI to help with ideation, development and debugging, while trying to understand what the code is actually doing rather than accepting “it compiled once” as quality assurance.
